For this lab, I built a single-screen Flutter gesture demo with tap, horizontal swipe, and long-press interactions. Tapping the large card changes its color, increases the tap count, and displays a short confirmation. Swiping across it changes the color, updates the swipe count, and identifies the swipe direction. Pressing and holding resets both counts and returns the card to its starting color. The responses are visible immediately, and light haptic feedback helps confirm that the app recognized the interaction.

These gestures make the interface direct to use. A tap is familiar for a quick action, while a swipe lets the user interact with the card without searching for a separate control. The long press provides a reset action in the same space, keeping the screen uncluttered. The card is a large target, so the interaction does not depend on accurately touching a small icon. The color transition and status message also make each action easier to understand.

One challenge was making the interactions distinct. A short tap and a long press begin with the same finger contact, so I used Flutter’s separate tap and long-press callbacks and tested them as different actions. I also made the horizontal gesture explicit by handling horizontal drag completion, which lets the app show left or right feedback. During refinement, I expanded the active gesture area to the entire card and added an animated color change, counters, and haptic feedback. This makes the result noticeable even when the user taps away from the icon.

I checked the interactions on an Android emulator by tapping, swiping in both directions, and long-pressing the card. Each action updated the message and counts as intended, and the long press restored the initial state. The screenshots show the starting screen and the visible result of each gesture. The app uses standard Flutter widgets and gesture callbacks, so the implementation remains small and easy to extend.
